# Reglas

Bienvenido a **Make The Market Great Again**.

## Cómo jugar

1. Escribe un monto (ej: `100`, `50k`, `2,5M`, `-1B`).
2. Pulsa **Bid** para crear una oferta pendiente.
3. Pulsa **Validate** para confirmarla y sumarla al total.
4. Pulsa **Cancel** para descartar la oferta pendiente.

## Valores

- Las ofertas pueden ser positivas o negativas.
- Se permite `0`.
- Los números grandes se abrevian automáticamente (`K`, `M`, `B`, `T`, ...).

## Fin de la partida

Pulsa **End Game** para ver el historial de ofertas validadas y el total; luego la partida se reinicia automáticamente.
