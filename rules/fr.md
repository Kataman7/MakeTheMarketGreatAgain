# Règles

Bienvenue sur **Make The Market Great Again**.

## Comment jouer

1. Saisissez un montant (ex : `100`, `50k`, `2,5M`, `-1B`).
2. Appuyez sur **Bid** pour créer une enchère en attente.
3. Appuyez sur **Validate** pour la confirmer et l'ajouter au total.
4. Appuyez sur **Cancel** pour annuler l'enchère en attente.

## Valeurs

- Les enchères peuvent être positives ou négatives.
- `0` est autorisé.
- Les grands nombres sont automatiquement abrégés (`K`, `M`, `B`, `T`, ...).

## Fin de partie

Appuyez sur **End Game** pour voir l'historique des enchères validées et le total, puis la partie se réinitialise automatiquement.
